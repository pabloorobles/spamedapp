Importar datos, copias de seguridad y preferencias
Datos
Descargar la plantilla de Excel
El archivo modelo para la carga inicial: una hoja por tipo de dato, con los títulos de columna que espera la aplicación, un ejemplo en cada una y una hoja de instrucciones. Completalo y después importalo con el botón de abajo.
Importar desde Excel
Trae clientes, vendedores, operadores, reservas y caja desde el libro BaseDatosSpamed. Se puede reemplazar todo o sumar sobre lo que ya está cargado.
Copias de seguridad
Hacer una copia ahora
Guarda el estado actual de la base. Además se hace una copia automática cada vez que cerrás el programa.
Restaurar una copia
Vuelve a un estado anterior. Antes de reemplazar nada, guarda una copia de lo que hay ahora.
Abrir la carpeta de datos
Ahí viven la base y las copias.

Versión, ubicación de la base, cantidad de registros y los últimos errores registrados. Sirve para pasarle el detalle a quien te da soporte. También se abre con Ctrl+Shift+D.
